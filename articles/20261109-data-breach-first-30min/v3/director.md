## 診断
構成・タイトルは妥当（title 4.0、promise 4.0）。購入意向は P1・P2・P3 が 4 に到達し、残るのは懐疑派 P4 の 3。満足度は P1・P2 が 4、P3・P4 が 3。

v2 から改善したもの：
- A の読み順案内（P1・P4 が評価）
- C の今日の3手と控え欄（P3 の購入意向 3→4）
- 「続きの記事」誘導の削除
- 監査の minor 6件の解消

残る 3 の原因（個別）：
- P3：満足度 3、situation_fit 3。C は「決めるための材料」（3機関の違い、費用、用語の意味）が無い。一次情報が未確認なので入口では書けない。用語説明の一言（信用情報機関＝ローンやカードの契約情報を扱う機関）は v2 にあって v3 で消えたので、これは入口で戻せる。
- P4：購入意向 3、満足度 3。IPA URL が未記入、著者の根拠が無い、中身の大半が IPA 準拠で AI でも再現できる（originality 3、non_substitutable 3）。
- originality と non_substitutable が全員 3 のまま。これは入口の構造的な限界で、実体験・一次情報（著者プロフィールが空）が要る。

## 実験1の観点での見立て（率直に）
結論：公開する価値はある。ただし「売れる」ではなく「入口型が売れるかを検証するための1本」としての価値。

- 実験1の目的は、点数ではなく実際の閲覧・スキ・購入で型と価格を判断すること（experiment-1.md）。ペルソナ評価は代理指標で、AI が作った読者像の評価なので、実際の読者がこう買うとは限らない。
- 前向きな材料：
  - 298円で購入意向が 4 人中 3 人、懐疑派でも 3。
  - 「無料のIPAで足りる人は買わなくてよい」と先に言う姿勢が、懐疑派にも好意的に読まれた。
  - 切迫性が高い場面（組1）。
  - critical 0、事実は sources と照合済み。
  - 印刷用チェックリストは再利用性が 4.5 と高い。
- 懸念材料：
  - originality と non_substitutable が全員 3。無料のIPAガイドや AI で骨格が再現できると、懐疑派は指摘している。
  - 満足度は 3.50 で「買ってよかった」の線に届いていない。P3・P4 は「値段相応」止まり。
  - 著者の根拠が空で、サムネイルや見出しだけでは買う理由が弱い可能性。
  - 「流出通知」は検索で競合が多く、検索流入が取れるかは不明。
- 実験の判断ルールとの関係：閲覧50以上で購入0なら型・価格を見直す。この記事は入口型の第1サンプル。本編と対にして比較してはじめて意味が出る。1本だけの結果で型の良し悪しを断定しない。
- 推奨：整理3の1・2・3は公開前に必須（特にURL）。整理1は時間があれば適用する。評価の追加ループは回さず、上限で止めて公開し、7日・14日後の実数値で判断する。これ以上ペルソナ評価の点数を上げようとしても、残る差は実体験・一次情報の不足で、入口での水増しは記事を平凡にする。
