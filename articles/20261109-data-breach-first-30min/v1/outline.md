# 構成 v1
tier：entry／テーマ：個人情報の流出通知が来た最初の30分にやること（チェックリスト）
作成日 2026-11-09（本文中の確認日も 2026-11-09 を基準にする）

## 約束（1文）
流出通知が来たとき、漏れた情報がA（ID・パスワード）／B（カード）／C（氏名・住所・電話・メール、または本人確認書類の画像）のどれでも、最初の30分を「5分／10分／15分」の順に、上から迷わず実行でき、30分で終わらないことは「今日はやらない」と線を引いて止められる。

## 価格：298円（理由）
`config/pipeline.json` の `tiers.entry.price_yen` で固定。加えて次の理由がある。
- 種類別の対処内容はIPAの無料ガイドと重なる（リサーチ A4）。高くしにくい。
- ペルソナの上限は P1・P3＝500円、P2＝980円、P4＝「298円まで、条件つき」。298円なら金額では迷わず、中身で判断される。
- note の競合は298円が中心という観察（competitors.md）とも合う。

## 想定文字数：無料 約900字（範囲 500〜1,000）／有料 約3,200字（範囲 1,500〜3,500）
有料の配分目安：凡例80／5分 350／10分 700／15分 500／電話メモ 450／線引き表 350／印刷用チェックリスト 450／つまずき・切り分け先 250／次の一歩 80

## 全体に通す書き方の約束（本文担当・評価担当への指示）
1. **【IPA】と【私見】の分離**：本文では各手順の行頭または直後に印をつける。
   - 【IPA】＝sources/ipa-guide-20261026.txt に書かれている内容（確認日 2026-11-09）。
   - 【私見】＝IPAに書かれていない、筆者の整理。「私の整理では」と書き、「推奨」「必ず」とは書かない。
   - 【公式で確認】＝未確認事項。断定しない。
2. 著者プロフィールは空。**体験談・実績・「何人を助けた」等は書かない**。筆者は「IPAの資料を時間枠に並べ直した人」としてだけ名乗る。経験欄が必要なら `【要記入：自分が流出通知を受けた経験（なければ欄ごと削除）】` を1か所だけ残す。
3. 煽らない（「今すぐ」「危険」「知らないと損」を使わない）。収益・補償の断言をしない。アフィリエイトリンクは入れない。
4. 数字は一次で確認できたものだけ：IPAガイド公開日 2026-10-26、IPA相談窓口 03-5978-7509（平日10:00〜17:00、IPAプレス 2026-11-02）。報道ベースの件数（「2,094件」等）は使わない。被害額の平均も書かない。
5. 1段落2〜4行、スマホ前提。表は3列以内。

## 型から外れる点（理由）
- 状況分岐型を土台にするが、entry のため「パターン別の独立見出し」は「時間枠の見出し＋A/B/C分岐」で作る。再利用のため、電話メモ・線引き表・印刷用チェックリストは独立見出しにする。
- 「繰り返しの読者が次回は有料部分だけ開く」ために、有料冒頭に「次回はここから」の案内を1行置く。

## 無料部分

### H2: 通知が来て、30分以上調べて、結局どれからやるか分からない人へ
- 目的：冒頭3行で悩みを言語化し、スクロールを止める。
- 書く内容：
  - つかみ3行（ペルソナの言葉）：「流出のお知らせが来たけど、何から手をつければいいのか分からない。このメールが本物かも分からない。パスワードを変えるだけで足りるの？」
  - 先に結論の一部：**最初にやるのは「通知のリンクを開かない」こと。確かめたいときは、自分で正規サイトを探してそこから**【IPA】。
  - この記事は「最初の30分」だけを扱う。今週・今月の作業は別（末尾）。
  - 確認日と出典：IPA「自分の個人情報等が漏えいした際の『対処』と『日頃の対策』」（2026-10-26）。【要記入：IPAガイドのURL】
- 想定ペルソナの反応：P1「まず何をするかが最初の画面で分かる」。P4「出典と確認日が最初にある」。

### H2: あなたはどれ？ A・B・Cの判定
- 目的：読者が自分の状況を特定する（判定チャート）。P1・P3 が離脱しない決め手。
- 書く内容（表または矢印の箇条書き。通知文を見て判断）：
  - A：ID・パスワードが漏れた可能性 → 次の10分でパスワード変更
  - B：クレジットカード情報が漏れた可能性 → 次の10分でカード会社へ連絡
  - C：氏名・住所・電話・メールのみ → 偽メール・偽電話への警戒／運転免許証など本人確認書類の画像も → 加えて信用情報機関への本人申告を検討【IPA】
  - 複数に当てはまる場合：全部の手順を実行（順番は有料部分）。
  - 通知に「何が漏れたか」が書かれていない場合は、サービスの公式サイト・サポート窓口で確認する【IPA 2.1】。
- 想定ペルソナの反応：P1「Aだと分かった」。P2「Bの電話メモが気になる」。P3「Cが別枠で書かれている」。

### H2: 無料のIPAガイドと何が違うか（買わなくてよい人も書きます）
- 目的：P4 の警戒に先回りし、誠実さで信頼を作る。IPAとの差を正直に出す。
- 書く内容：
  - 先に認める：**情報の種類ごとの対処内容は、IPAの無料ガイドに書かれている。それだけで足りる人は、この記事は不要**（目安：自分で順番を決められる／時間に余裕がある／通知が1件だけ）。
  - IPAは「何が漏れたらこう対処」を種類別に書く。IPAには載っていない、この記事の差は4つだけ（【私見】の整理であることも明示）：
    1. 通知直後の**時間枠の順番**（最初の5分／次の10分／残り15分）
    2. その場で選ぶ**A/B/C分岐**
    3. **カード会社に電話するときの「言う順メモ」**
    4. **30分で終わる作業／終わらない作業の線引き**と、**印刷用チェックリスト**
  - 正直に書く：ChatGPT などに聞いても似た手順は出るかもしれない。この記事の価値は、IPAに書かれたこと【IPA】と筆者の整理【私見】を分けて示した、確認日つきの1ページ完結の形にある。
  - 書かないこと：補償が受けられるか、事業者の責任、被害額の見込み。これらは専門窓口に切り分ける（有料部分に一覧）。
- 想定ペルソナの反応：P4「正直だ。IPAで足りるか自分で判断できる。差の4点がPDFのチェックリストなら298円は検討範囲」。P1「後悔しない記事か分かる」。

### H2: この記事で手に入るもの（有料部分の目次）
- 目的：何が分かるかを見せ、どうやるかの核心を有料にする。
- 書く内容（目次＋「得るもの」を1行ずつ）：
  1. 最初の5分：やることと、やらないこと
  2. 次の10分：A/B/Cの分岐手順
  3. 残り15分：明細・家族共有・申告の「予約」まで
  4. カード会社に電話するときの言う順メモ
  5. 30分で終わる作業／終わらない作業の線引き表
  6. 印刷用チェックリスト（コピーして使う）
  7. つまずきと切り分け先（188、警察、弁護士、カード会社の規約）
  - 「次回流出通知が来たら、この記事の6番だけ開けば使えます」と1行添える。
- 想定ペルソナの反応：P2「電話メモとチェックリストが本当にあるなら買う」。P3「切り分け先が一覧で分かる」。

## ===== ここから有料（理由：無料で「判定（自分はどれか）」と「IPAとの違い・買わなくてよい人」までを見せた。有料は『判定後に何をどの順でやるか』の実行手順と、そのまま使える成果物（電話メモ・線引き表・印刷用チェックリスト）。H2「最初の5分」の直前で切る。最初の1手（リンクを開かない）だけは無料に出してあるので、不安だけ煽って売る形にはならない） =====

## 有料部分

### H2: 読み方と凡例（次回はここから）
- 読者が得るもの：【IPA】【私見】【公式で確認】の意味が分かる。2回目以降の読者が迷わず目的の見出しに飛べる。
- 書く内容：確認日 2026-11-09。凡例3種。「次回は6番の印刷用チェックリストから」。本文の判断はIPAの内容に基づくが、個別事案の法的判断・補償の見込みは書かない旨を1行。

### H2: 最初の5分：やること／やらないこと
- 読者が得るもの：焦っている最中に「まず手を止める」べき行為が分かる。通知の真偽の確かめ方。
- 書く内容：
  1. 【IPA】通知のリンク・電話番号・添付は使わない。URLからの入力、アプリのインストールもしない。
  2. 【IPA】確かめたいときは、正規サイトを自分で検索して、そのサイトの案内・サポート窓口から確認。**ブックマークや公式アプリ内のお知らせも同じ考え方**は【私見】（IPAは「正規のサイトを調べてそこから」と書く）。
  3. 【私見】通知の日時と文面をスクリーンショットで保存（IPAに記載なし。後で窓口に説明するときの材料）。
  4. 【IPA】冷静に、どの情報が漏れたかを確認（連絡内容、公式サイトの案内、サポート窓口）。
  5. 返信しない、入力しない、リンクを押さない。
  - 注意書き：IPAは「突然来るメール・SMSは基本すべて詐欺と考える」とも書く。**流出通知そのものが偽物の場合もあるため、通知の内容は『本当に自分が対象か』を公式側で確認してから信じる**【IPAの方針に沿った私見】。
- 想定ペルソナの反応：P1「リンクを開かなくてよかった」。P4「IPAの該当を確認できる」。

### H2: 次の10分：A/B/Cで分かれる手順
- 読者が得るもの：自分の分岐だけを上から実行できる。使い回しの洗い出しの具体的な方法（P1）。
- 書く内容（小見出し＝A・B・C。それぞれ独立して読める）：
  - **A（ID・パスワード）**
    - 【IPA】漏えいしたサービスのパスワードを、長く複雑なものに変更。同じパスワードの他サービスも変更。
    - 【私見】順番：①漏えい元を変更 ②使い回している可能性が高い順に（メール、ネットバンキング、通販、SNS）の**一覧メモを作る**。今日変更するのは①と、①と同じパスワードを使っている主要なもの。全サービスは今日やらない。
    - 【私見】洗い出しのやり方：ブラウザやスマホの保存済みパスワード一覧で同じ文字列を探す（具体の画面は機種で違うため、手順は「設定の検索窓でパスワードと入力」程度に留める）。
    - 【IPA】多要素認証・パスキーは日頃の対策として推奨。**今日入れるかは【私見】で「今日は予約まで」**（設定は30分で終わらない場合がある）。
  - **B（カード）**
    - 【IPA】カード会社に連絡して、不正利用の有無の確認、利用停止・再発行を相談。
    - 連絡先は、カード裏面か公式サイトで確認【私見】（通知記載の電話番号は使わない）。
    - 電話のかけ方は次の「言う順メモ」へ。**一律に『必ず止める』とは書かない**。止める／様子を見るは、カード会社と相談して決める【IPAの表現「相談」に沿う】。
  - **C（氏名・住所・電話・メール／書類画像）**
    - 【IPA】突然の連絡は詐欺と考える。リンクを押さない。不審な着払いは受け取らない。
    - 【IPA】本人確認書類の画像が漏れた場合、信用情報機関（JICC、CIC、KSC）への本人申告を検討。
    - 【公式で確認】受付方法・手数料・期間・混み具合は各機関の公式で確認。
    - 【私見】今日は「どの機関に、どの方法で申し込むかを決める」まで。
- 想定ペルソナの反応：P1「Aの順番が分かる」。P2「Bの分岐が明確」。P3「Cが独立して書かれ、書類の場合の線引きがある」。

### H2: 残り15分：明細・家族・予約まで
- 読者が得るもの：「30分でやる」と「予約だけ」を区別した、仕上げの手順。
- 書く内容：
  - **B**：【IPA】利用明細に身に覚えのない決済がないか確認（今日1回＋当面定期的に）。【私見】カード再発行になりそうなら、公共料金・サブスク・携帯料金など**カードで払っているものの一覧を作る**（付け替えは今週。未払いを避けるため、付け替え時期はカード会社と相談）。
  - **C**：【IPA】偽メール・偽SMS・詐欺電話・不審郵便への警戒。【私見】家族にも共有（文例1つ：「届いたメールやSMSのリンクは押さずに、私に見せてください。着払いの荷物は受け取らないでください」。短い文例を本文に実際に載せる）。
  - **A**：変更したパスワードと、これから変更するサービスの一覧が手元にあることを確認。
  - 【私見】終了時：「誰に・何を・いつ連絡したか」を3行でメモ（本編の対応ログ表の簡易版。ここでは書式を載せない）。
  - 迷ったら相談：IPA情報セキュリティ安心相談窓口 03-5978-7509（平日10:00〜17:00。IPAプレス 2026-11-02）。
- 想定ペルソナの反応：P2「付け替えの一覧は前回できなかった。明細の見張りが最低限書いてある」。P3「家族への文例が使える」。

### H2: カード会社に電話するときの「言う順メモ」
- 読者が得るもの：Bの人が電話で言葉に詰まらない。P2 の購入決め手。独立見出し。
- 書く内容（そのまま読み上げ・コピー可の番号付きメモ）：
  1. 名乗りと用件：「〇〇社から、カード情報が漏れた可能性があるという通知を受けました。通知の日付は〇月〇日です。」
  2. 対象の確認：「私のカードが対象かどうか、確認できますか。不正な利用が出ていないかも確認してください。」
  3. 取れる対応の確認：「利用停止と再発行の方法と、手数料の有無を教えてください。」
  4. 再発行の場合：「新しいカードが届くまでの期間と、旧カードがいつ使えなくなるかを教えてください。引き落としの登録はどう扱われますか。」
  5. 補償に関する質問（見込みは書かず質問だけ）：「今回の件で不正利用があった場合の扱いは、どの規約のどこを見ればよいですか。」
  6. 控え：担当者名・受付番号・日時・言われたことをメモ。
  - 記入欄：〔通話日時〕〔担当〕〔受付番号〕〔決まったこと〕。
  - 注意：補償の可否・範囲は書かない。【公式で確認】カード会社の規約。つながりにくい場合は、公式サイトの案内を確認し、再度かける。
- 想定ペルソナの反応：P2「前回これがなくて15分かかった。実際に使える」。P4「IPAにない成果物」。

### H2: 30分で終わる作業／終わらない作業
- 読者が得るもの：「今日はここまででよい」という安心と、次にやることの置き場所。P1・P3 の決め手。
- 書く内容（2列の表。A/B/Cの印つき）：
  - 30分で終わる：通知の真偽確認／種別の分類／漏えい元のパスワード変更（A）／カード会社へ電話（B）／明細の1回目の確認（B）／家族への共有（C）／3行メモ
  - 30分で終わらない（予約・方針決めまで）：使い回しパスワードの全洗い出しと総入れ替え（A）／多要素認証・パスキーの設定（A）／引き落とし先の付け替え（B）／信用情報機関への本人申告（C。方法・手数料は各機関の公式で確認）／明細の継続的な見張り（B）／対応の記録の整理
  - 「終わらない側」は、今週・今月に回す。ここが次の記事（本編）の内容。
  - 【私見】線引きの基準：①すぐに被害が拡大しうるか ②相手の窓口に依存するか ③設定に時間がかかるか。
- 想定ペルソナの反応：P1「止めてよい線が分かる」。P3「信用情報の申告は予約まででよい」。

### H2: 印刷用チェックリスト（コピーして使う）
- 読者が得るもの：不安な状態でも上から順に実行できる1ページ。次回は有料部分のここだけ開けば使える。
- 書く内容（チェックボックス形式。スクショ・印刷向けに短く）：
  - 確認日と出典：2026-11-09／IPAガイド 2026-10-26／【要記入：IPAガイドのURL】
  - 最初の5分：□リンクを押さない □公式から確認 □通知を保存 □何が漏れたか確認
  - 次の10分：□A パスワード変更＋一覧メモ □B カード会社へ電話＋受付番号 □C 偽メール警戒
