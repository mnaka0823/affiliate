# 流出通知が来た、どうする？漏れた情報別に選ぶ最初の30分｜電話メモと印刷用チェックリスト

流出のお知らせが来たけれど、何から手をつければいいのか分からない。このメールが本物かどうかも分からない。パスワードを変えるだけで足りるのか。

最初の1手だけ先に書きます。**通知のリンクは開かない。確かめたいときは、自分で正規サイトを調べて、そこから確認する。** IPAは、突然届くメール・SMSのリンクを押さないよう書いています。流出通知にも当てはめて、という筆者の判断です。

この記事は「最初の30分」だけを扱います。今週・今月の作業は別です。確認日は2026-11-09。出典はIPA「自分の個人情報等が漏えいした際の『対処』と『日頃の対策』」（2026-10-26公開）です。【要記入：IPAガイドのURL】

## あなたはどれ？ A・B・Cの判定

通知文で「何が漏れたか」を見て選びます。

- Q1. ID・パスワードが漏れた可能性がある？ → はい：Aへ／いいえ：Q2へ
- Q2. クレジットカード情報が漏れた可能性がある？ → はい：Bへ／いいえ：Q3へ
- Q3. 氏名・住所・電話・メールのみ、または免許証など本人確認書類の画像？ → はい：Cへ／いいえ・分からない：通知元の公式サイトかサポート窓口で確認。迷ったらIPA相談窓口 03-5978-7509（平日10:00〜17:00、IPAプレス発表 2026-11-02）

複数に当てはまるなら、全部の手順をやります。

## 無料のIPAガイドで足りる人は、買わなくて大丈夫です

情報の種類ごとの対処は、IPAの無料ガイドに書かれています。自分で順番を決められる人、時間に余裕がある人、通知が1件だけの人は、ガイドだけで足ります。

この記事の差は次の4つだけで、いずれも私の整理です。

1. 時間枠の順番（5分／10分／15分）
2. A/B/Cの分岐
3. カード会社に電話するときの「言う順メモ」
4. 30分で終わる作業・終わらない作業の線引きと、印刷用チェックリスト

たとえば「言う順メモ」の4番（カードを再発行するとき）は、こういう一文です。

> 新しいカードが届くまでの期間と、旧カードがいつ使えなくなるかを教えてください。引き落としの登録はどう扱われますか。

AIに聞いても似た手順は出るかもしれません。違いは、IPAに書かれたことと私の整理を分け、確認日つきで1ページにまとめた点です。補償や事業者の責任の見込みは書きません。

## 読み方と凡例（次回は6番から）

確認日は2026-11-09です。印は、各ブロックの最初に付けます。

- 【IPA】：IPAガイド（2026-10-26）に書かれている内容
- 【私見】：IPAに書かれていない、私の整理。推奨ではありません
- 【公式で確認】：私が確認できていないこと。各機関の公式で確認してください

個別の法的判断や補償の見込みは書きません。2回目以降は「印刷用チェックリスト」から開けば使えます。

## 最初の5分：やること／やらないこと

1. 【IPA】メール内のリンクは押さない。URLから情報を入力しない、アプリを入れない。
2. 【私見】通知に書かれた電話番号にはかけない。添付も開かない。
3. 確かめるときは、正規サイトを調べて、そのサイトの案内かサポート窓口から【IPA】。検索するなら、広告表示でないか、URLが公式のものかを見る【私見】。ブックマークやカード裏面のほうが確実です。
4. 【私見】通知の日時と文面をスクリーンショットで保存。後で窓口に説明するときの材料になります。
5. 冷静に、どの情報が漏れたかを確認する（通知の内容、公式サイトの案内、サポート窓口）【IPA】。
6. 返信しない、入力しない、リンクを押さない。

IPAは、突然届くメールやSMSは基本すべて詐欺と考えるよう書いています。流出通知そのものが偽物の可能性もあるので、「本当に自分が対象か」は公式側で確かめてから信じる、という扱いにしています【私見】。

## 次の10分：A/B/Cの手順

自分の分岐だけ読めば進められます。

### A　ID・パスワード

1. 【IPA】漏れたサービスのパスワードを、長く複雑なものに変更する。
2. メール・ネットバンキングで、①と同じパスワードを使っていないか確認する。使っていれば今日変える。IPAは、同じパスワードを使い回している他サービスも変更するよう書いています【IPA】。メールと銀行を先にするのは、乗っ取られたときの影響が大きいからです【私見】。
3. 残りは一覧メモにして、今週に回す。

一覧メモの作り方は短く済みます。

- 端末やブラウザの保存済みパスワード一覧を開く（画面は機種で違います。設定の検索窓に「パスワード」と入れて探してください）
- ①と同じものに印をつける
- サービス名だけを紙かメモ帳に書く

多要素認証（パスワードのほかに確認を1回足す仕組み）とパスキー（パスワードの代わりに端末の認証で入る仕組み）は、IPAが日頃の対策として推奨しています【IPA】。今日は「いつ入れるか」を決めるまでにします【私見】。

### B　クレジットカード

- 【IPA】カード会社に連絡して、不正な利用がないかの確認、利用停止や再発行を相談する。
- 【私見】連絡先はカード裏面か公式サイトで確認。通知に書かれた番号は使わない。
- 止めるか様子を見るかは、カード会社と相談して決めます。一律に「止めましょう」とは言えません。電話のメモは後ろの章にあります。

### C　氏名・住所・電話・メール／本人確認書類の画像

- 【IPA】突然のメール・SMSは詐欺と考える。リンクを押さない。不審な着払いは受け取らない。
- 【IPA】免許証などの画像が漏れた場合は、信用情報機関（JICC、CIC、KSC）への本人申告を検討。
- 【公式で確認】受付方法・手数料・期間・混み具合は、各機関の公式で確認してください。
- 【私見】今日は「どの機関に、どの方法で申し込むか」を決めるところまで。

## 残り15分：明細・家族・予約まで

- **B**：【IPA】利用明細に身に覚えのない決済がないか確認する。当面は定期的に。
- **B**：【私見】再発行になりそうなら、カードで払っているものの一覧を作る。並べ方は、止まると困る順（携帯料金・公共料金・保険など）。付け替えは今週。時期はカード会社と相談します。
- **C**：【IPA】偽メール・偽SMS・詐欺電話・不審な郵便に警戒する。【私見】家族にも共有する。文例です。

> 届いたメールやSMSのリンクは押さずに、私に見せてください。着払いの荷物は受け取らないでください。

- **A**：変更済みのものと、これから変えるものの一覧が手元にあるか確認。
- **全員**：【私見】「誰に・何を・いつ連絡したか」を3行でメモ。

迷ったらIPA情報セキュリティ安心相談窓口（03-5978-7509、平日10:00〜17:00。IPAプレス発表 2026-11-02）に相談できます。

## カード会社に電話するときの「言う順メモ」

そのまま読み上げられます。［ ］を埋めてください。

> 1. ［サービス名］から、カード情報が漏れた可能性があるという通知を受けました。通知の日付は［月日］です。
> 2. 私のカードが対象かどうか、確認できますか。不正な利用が出ていないかも確認してください。
> 3. 利用停止と再発行の方法と、手数料の有無を教えてください。
> 4. 再発行の場合、新しいカードが届くまでの期間と、旧カードがいつ使えなくなるかを教えてください。引き落としの登録はどう扱われますか。
> 5. 今回の件で不正利用があった場合の扱いは、どの規約のどこを見ればよいですか。
> 6. 担当者名と受付番号を教えてください。

控え欄：〔通話日時　　〕〔担当　　〕〔受付番号　　〕〔決まったこと　　〕

補償の可否や範囲は、カード会社の規約によります【公式で確認】。つながらないときは、公式サイトの案内を見て、時間をおいてかけ直します。

## 30分で終わる作業／終わらない作業

| 30分で終わる | 30分で終わらない（予約まで） |
|---|---|
| 通知の真偽確認 | 使い回しの残りの洗い出しと入れ替え（A） |
| A/B/Cの分類 | 多要素認証・パスキーの設定（A） |
| 漏れたサービスと、同じパスワードの主要なもの（メール・銀行）の変更（A） | 引き落とし先の付け替え（B） |
| カード会社へ電話（B） | 明細の継続的な確認（B） |
| 明細の1回目の確認（B） | 信用情報機関への本人申告（C） |
| 家族への共有（C）、3行メモ | 対応の記録の整理 |

線引きの基準は、①すぐ被害が広がりうるか ②相手の窓口に依存するか ③設定に時間がかかるか、です【私見】。右の列は今週・今月に回します。

## つまずきと、切り分け先

- 通知の真偽が分からない：公式サイトの案内かサポート窓口で確認
