# ビジュアル試作1：ChatGPTに貼る指示文（アイコン4案＋見出し画像3案）

生成はChatGPT側で行う運用。スタイルは `knowledge/visual-style.md`（v1）。判定シートは `knowledge/visual-trial-1.md`。

## 進め方
1. ChatGPTで**新しいチャット**を開く（同じチャットで7枚続けると、雰囲気が揃いやすい）。
2. 下の「共通の指示文」を、まず1回だけ貼る。
3. 画像ごとの指示を1つずつ貼って、生成する。
4. 気に入らない点があれば、同じチャットで「ここだけ直して」と頼む（例：「文字を『最初の30分』に直して」「チェックマークを大きく」）。
5. 画像に名前をつけて保存する：`icon-1.png` 〜 `icon-4.png`、`header-1.png` 〜 `header-3.png`。
6. 選ぶのはご自身で行います。ここまでで指示書の役目は終わりです。
7. **任意**：画像の検査や比較を私に頼みたいときは、画像をチャットに貼るか、リポジトリの `images/trial-1/` に置いて頼んでください（頼まれたときだけ、下の「確認の基準」で見て比較表にします）。

```
背景は無地の淡い青灰色（#EAF2F8）。濃紺（#1D3557）、青（#2F6DB5）、ティール（#2A9D8F）を基調にし、
差し色の黄色（#F2B705）を1か所だけ小さく使う。落ち着いて信頼できる雰囲気。人物の顔は描かない。
ロゴ・商標・実在の企業や官公庁の表現を入れない。怖さや不安を煽る表現（フード姿の人物、赤い警告、ドクロ）を入れない。
余白を広く取る。

画像の指示は、次のメッセージから1枚ずつ送ります。了解したら「了解」とだけ返してください。
```

## 確認の基準（検査を頼まれたとき、または自分で見るときの目安）
1. 日本語の文字が崩れていないか（header-1、header-2）
2. スタイルガイドの色・画風・角丸の印象に合っているか
3. 怖さや不安を煽る表現、実在の人物・ロゴを想起させる要素がないか
4. 主役が中央の帯（見出し）／中央の円（アイコン）に収まっているか
5. 小さく表示しても分かるか（アイコン。48pxに縮めて確認する）
6. 7枚を並べて、雰囲気が揃っているか

## アイコンが決まったあと
決まったアイコンをChatGPTに添付して、「このアイコンと同じ雰囲気・同じ色で、見出し画像を作って」と頼むと、全体の雰囲気が揃いやすい。
