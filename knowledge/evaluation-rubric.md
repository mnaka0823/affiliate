# 評価基準（全評価エージェント共通）

点数は「感想を先に自由に書く → 下のアンカー文のうち一番近いものを選ぶ」の順で決める。
いきなり数字をつけない（直接数値で聞くと人間の反応から外れやすいため）。

## A. 購入意向（無料部分とタイトル・価格だけを見て判断）
| 点 | アンカー文（このペルソナの心の声） |
|---|---|
| 1 | 「自分には関係ない／怪しい。絶対に買わない」 |
| 2 | 「少し気になるが、この値段なら買わない。無料の情報で足りそう」 |
| 3 | 「迷う。レビューや他の人の反応を見てから決めたい」 |
| 4 | 「たぶん買う。自分の悩みが解決しそうな気がする」 |
| 5 | 「今すぐ買う。むしろ安いと感じる」 |

## B. 満足度（購入したつもりで有料部分まで読んだあと）
| 点 | アンカー文 |
|---|---|
| 1 | 「金を返してほしい。無料部分以上のものがない」 |
| 2 | 「どこかで読んだ内容。払った価値は薄い」 |
| 3 | 「値段相応。悪くはないが人には勧めない」 |
| 4 | 「買ってよかった。明日から試せることがある」 |
| 5 | 「値段以上。人に勧めたい／この著者の次の記事も買う」 |

## C. 診断項目（各1〜5、同じくアンカーで判断）
- **タイトルの刺さり**：一覧で見たときに指が止まるか
- **約束の明確さ**：無料部分を読んで「有料部分で何が手に入るか」が具体的にわかるか
- **有料ラインの位置**：一番知りたいところで切れているか（早すぎて不信感／遅すぎて満足して買わない、になっていないか）
- **独自性**：ネットや無料記事で手に入らない情報・経験・手順があるか
- **実行可能性**：読後にすぐ行動できる手順・テンプレ・具体例があるか
- **信頼性**：著者がそれを語る根拠（実績・経験・データ）が示されているか
- **読みやすさ**：スマホで読んで疲れないか（段落・見出し・箇条書き）

## D. 品質監査（quality-auditor が担当）
重大度は次の3段階。**critical が1件でもあれば合格にしない。**
- **critical**：事実の誤り、根拠のない収益保証（「誰でも月100万」など）、法令・規約違反のおそれ、他者の文章の流用、広告表記のないアフィリエイト
- **major**：根拠の弱い断定、古い情報、無料部分と有料部分の約束の食い違い、AIっぽい定型表現の多用
- **minor**：誤字脱字、表記ゆれ、冗長な文

## E. 総合点の算出（improvement-director が算出）
```
総合点 = 0.45 × 平均購入意向 + 0.45 × 平均満足度 + 0.10 × 平均診断項目
```
合格条件・ループ上限は `config/pipeline.json` を参照。
