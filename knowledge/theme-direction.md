# 記事の方向性（テーマ選定方針）

このパイプラインが狙うのは**「繰り返し検索される、手順が決まった悩み」**。
単価を上げやすいテーマより、何度も検索されるテーマを優先する。
trend-researcher・persona-builder・structure-architect・improvement-director が毎回読む。

## テーマの6条件
| # | 条件 | 確認の仕方 | 必須 |
|---|---|---|---|
| C1 | **答えが決まっている悩み**（手順・書式・段取り） | 「正しいやり方」があり、読者がそれを知らないだけか | 必須 |
| C2 | **古くなりにくい**（1年後も同じ悩みが残る） | 制度・ツールの仕様変更で中身が丸ごと変わらないか。変わる部分は一部で済むか | 必須 |
| C3 | **調べる人はいるのに、まとまった情報が少ない** | 検索結果が断片的（Q&A・個人ブログの一部・公式の分かりにくい説明）で、通しで解説したものがない | 必須 |
| C4 | **状況によってやることが変わる** | 「〇〇の場合は」で手順が3通り以上に分かれるか | 必須 |
| C5 | **経験があれば書ける**（専門資格が不要） | 弁護士・税理士・医師などの独占業務の助言にならないか。著者プロフィールの経験で書けるか | 必須 |
| C6 | **定期的に同じ状況に陥る**（月に数回、年に数回など） | 毎回やり方を忘れて検索し直す類の作業か | 加点（絶対ではない） |

必須条件を1つでも満たさない候補は選ばない。

## なぜこの条件か
- C1・C4：答えが決まっていて状況で分かれるので、**「自分の場合はどうするか」がまとまっていること自体に価値が出る**。無料で一般論を見せ、有料で状況別の正解を渡す形が自然に作れる。
- C2：一度書いた記事が長く売れ続ける（量産しても在庫が腐らない）。
- C3：検索してもまとまった答えが見つからない人が、お金を払ってでも時間を節約したいと思う。
- C5：著者の実体験で書けるので、AIだけでは書けない独自性が出る。資格が必要な領域の誤った助言による事故も避けられる。
- C6：同じ読者が何度も困るので、ブックマーク・リピート・関連記事の購入につながる。

## 各テーマで必ず決める7項目
1. テーマ名
2. 想定される検索キーワード（3つ）
3. この悩みが発生する場面
4. 状況の分かれ方（3つ）
5. 無料部分で見せるべき内容
6. 有料部分に置くべき内容
7. 同じ読者が次に困りそうなこと（→ 次の記事・シリーズの候補）

## 記事の基本の型（状況分岐型）
```
無料部分
  1. よくある場面と悩み（読者の言葉で）
  2. 全体の流れ（共通の手順の地図）
  3. 「あなたはどのパターン？」判定チャート（状況の分かれ方）
  4. 共通部分の手順の一部・つまずきやすい点の予告
  5. 有料部分の目次（パターンごとに何が手に入るか）
───── ここから有料 ─────
有料部分
  6. パターン別の詳しい手順（パターンA／B／C）
  7. そのまま使える書式・テンプレ・文例
  8. つまずきやすい点と対処（経験談）
  9. 当日・提出前のチェックリスト（次に同じ状況になったとき見返す用）
  10. 次に困りそうなことの予告（関連記事への導線）
```

## シリーズ化
「同じ読者が次に困りそうなこと」を次の記事のテーマ候補にし、記事同士を相互リンクする。
note のマガジン（まとめ売り）にしやすい。
