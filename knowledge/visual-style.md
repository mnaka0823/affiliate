# ビジュアルスタイルガイド（v1：ヒアリング2回目まで反映。試作の選定待ち）

見出し画像・記事内の挿絵・アカウントのアイコンで、全体の雰囲気を揃えるための基準。
image-director と `/note-image` が、画像を作る前に必ず読む。
`【未定】` が残っている項目は、決まるまで画像を生成しない（試作を除く）。

## 決まったこと（ヒアリング1回目）
| 項目 | 決定 |
|---|---|
| 画風 | フラットな図解風イラスト。単純な形、少ない色、影とグラデーションは使わない |
| アイコン | 記号型のシンボル（顔出しなし） |
| 配色 | 青〜ティールを基調にし、差し色は1色だけ |
| 見出し画像の文字 | 短い文字（数文字〜1行）をAIに入れさせ、崩れたら作り直す |
| アイコンのモチーフ | 手帖＋チェックリスト（太い単純な形、要素は3つまで） |
| 形の印象 | 角丸の中間（角を少し丸める。尖りすぎず、丸すぎない） |
| 差し色 | 黄色 `#F2B705`（1色、注意・ポイントにだけ使う） |
| 見出し画像の構図 | 中央に大きなモチーフ＋余白（モチーフは1つ、小物は3つまで） |
| 最終判断 | 候補を並べて、ユーザーが選ぶ。AIが自動で採用しない |

## 読者に合わせた方針
- 読者は不安な生活者と、疑い深い会社員。画像は不安を煽らず、落ち着きと信頼が伝わるようにする。
- 避ける：フードの人物・ハッカー・ドクロ・赤い警告表示など、怖さを煽る定番の絵。派手なグラデーションや3D風。実在の企業・官公庁のロゴや公式を装った表現。実在の人物に似せた絵。
- 顔は描かない（人物を入れるときは、顔のないシンプルな人型にする）。

## 配色
| 役割 | 色 | 用途 |
|---|---|---|
| 基調（濃） | 濃紺 `#1D3557` | 主役の形、文字 |
| 基調（中） | 青 `#2F6DB5` | 面、アイコン |
| 基調（明） | ティール `#2A9D8F` | 補助の面、チェックマーク |
| 背景 | 淡い青灰 `#EAF2F8` | 無地の背景 |
| 差し色 | 黄色 `#F2B705` | 注意点・強調に1か所だけ（面積は全体の5%以内） |

## 形と線
- 形の印象：角丸の中間（角を少し丸める）。
- 線：輪郭線なし、または細く一定の線のどちらかに統一する（混ぜない）。
- 背景は無地。小物は多くても3つまで。余白を広く取る。

## 画像の種類ごとの仕様
### 1. アカウントのアイコン
- 生成は正方形（`1024x1024`）。noteでは丸く切り取られるので、主役は中央の約70%の円に収める。
- 文字は入れない（入れても1文字）。小さく表示されても形で分かること（48pxに縮めて確認する）。
- モチーフ：手帖＋チェックリスト。太い単純な形にし、要素は3つまで（手帖、チェックマーク、もう1つ）。
- 背景は無地1色。シンボルは1つ。

### 2. 見出し画像（記事の先頭）
- 横長で生成する（`1536x1024`）。noteの一覧で横長にトリミングされても欠けないよう、主役は縦の中央の帯（高さの約55%）に収め、上下は背景だけにする。
- 構図：中央に大きなモチーフ＋余白。モチーフは1つ、小物は3つまで。
- 文字：短い語句だけ（記事の `titles.md` の「見出し画像の文言案」から選ぶ。1行・数文字〜15字以内）。崩れたら作り直す（1回まで。それ以上は文字なしの案に切り替える）。
- 1記事につき候補3案を作り、ユーザーが選ぶ。

### 3. 記事内の画像
- **文字を含む図（判定チャート、時間枠の流れ、線引き表、チェックリスト）はAI画像にしない。** 日本語の文字が崩れ、手順の間違いは読者の被害につながるため。表・コードブロック・図（SVGなど）で決まった形で作る。
- AI画像は、文字なしの挿絵（章の区切りの雰囲気、場面の説明）に限る。1記事に多くても3枚。
- すべて同じ画風・配色で作る。

## 画像生成に毎回付ける共通の指示文
```
フラットなベクター風のイラスト。単純な形で、角を少し丸めた角丸の形を基本にする。影とグラデーションなし、輪郭線なし。
背景は無地の淡い青灰色（#EAF2F8）。濃紺（#1D3557）、青（#2F6DB5）、ティール（#2A9D8F）を基調にし、
差し色の黄色（#F2B705）を1か所だけ小さく使う。落ち着いて信頼できる雰囲気。人物の顔は描かない。
ロゴ・商標・実在の企業や官公庁の表現を入れない。怖さや不安を煽る表現（フード姿の人物、赤い警告、ドクロ）を入れない。
余白を広く取る。
```
個別の指示（モチーフ、構図、文字）は、この指示文の後ろに足す。

## 一貫性を保つ方法
- アイコンが確定したら、その画像を参照画像にして `edit`（`--image`）で見出し画像を作る。雰囲気が引き継がれやすい（効果は試して確認する）。
- 共通の指示文は変えない。変えるのは、モチーフ・構図・文字だけ。
- 確定した画像の指示文と設定は、同名の `.json` に残っている。次回はそれを再利用する。

## 確認の基準（画像を出したあと、必ず見る）
1. 文字が崩れていないか（日本語）
2. スタイルガイドの色・画風に合っているか
3. 怖さや不安を煽る表現、実在の人物・ロゴを想起させる要素がないか
4. 主役が中央の帯（見出し）／中央の円（アイコン）に収まっているか
5. 小さく表示しても分かるか（アイコン）
