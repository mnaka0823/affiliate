# 競合メモ（note内の同テーマの有料記事）

noteの検索ページとAPIは `robots.txt` で自動アクセスが禁じられているため、**ご自身のブラウザで見た結果をここに貼ってください**。
trend-researcher と persona-evaluator が、価格案・差別化・優先順位の見直しに使います。

## 貼り方（テーマごとに1ブロック。スクリーンショットをチャットに貼るだけでも構いません）

```
## テーマ：<テーマ名>（検索した言葉：<キーワード>） 確認日：YYYY-MM-DD
| 順位 | タイトル | 価格 | スキ数 | 著者 | URL | 無料部分の冒頭・目次で気づいたこと |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
```

見るポイント：
- 有料記事の上位5〜10本の価格帯とスキ数（スキ数は売れ行きの目安になるが、販売数ではない）
- 同じ内容を無料で出している記事があるか
- 目次を見て、自分の案にあって競合にないもの／競合にあって自分の案にないもの

#### タイトルの型（文面そのままではなく型だけを記録）
- 【数字の変化】＋場面＋方法｜テンプレ N つ（例：残業60分→20分）
- 感情の一言＋「と固まる朝に」｜方法と所要時間
- 「A」か「B」か｜選び方（比較の型）
- 損失回避：「〜になる損」「〜は時間の損」
- 成果物を明示：「テンプレつき」「手取り計算つき」「全手順」「ロードマップ」
- 「調べた」型：【◯◯が調べた】で検証の姿勢を示す
- 「｜」で前半＝場面や感情、後半＝方法や成果物

#### 示唆（私の解釈）
- 価格の実勢は298円が中心で、980円以上は「全手順＋テンプレ」の大きめの記事。500〜980円の価格案は、やや高めに置いている。
