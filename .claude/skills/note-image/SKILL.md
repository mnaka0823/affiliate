# 画像の生成・編集

依頼：$ARGUMENTS

`scripts/image.py` を使って OpenAI Images API を呼び、画像をフォルダに保存する。
設定は `config/images.json`（モデル・サイズ・品質・保存先）と環境変数で決まる。

## 絶対に守ること
- **APIキーを表示・保存・要求しない。** `.env` や環境変数の中身を読んで出力しない。キーが無いときは設定方法を案内して止まる。
- **利用料金がかかる。** 1回の依頼で呼ぶのは1回まで。`--n` を2以上にする、品質を `high` にする、失敗して再実行する、のどれかをするときは、先に一言伝えてから実行する。自動で何度も作り直さない。
- **画像を編集するときは、元の画像を外部（OpenAI）に送る。** 個人情報（顔、氏名、住所、書類、スクリーンショットの中の個人情報）が写っていそうなときは、送ってよいか先に確認する。
- 実在の人物に似せた画像、実在の企業・官公庁（IPAなど）のロゴや公式を装った画像は作らない。
- 元の画像は上書きしない（スクリプトは常に新しいファイルとして保存する）。

## 手順
1. **確認**（そのセッションで初めてのときだけ）：`python3 scripts/image.py check` を実行する。
   - `OPENAI_API_KEY : 未設定` なら、次を案内して終了する：「ターミナルで `export OPENAI_API_KEY=...` を設定するか、プロジェクト直下の `.env` に `OPENAI_API_KEY=...` と書いてください（`.env` は git に入りません）。キーはチャットに貼らないでください。」
2. **依頼を指示文に直す。**
   - 何を・どんな雰囲気で・何を入れないか、を1〜3文で書く。ふだんの言葉の依頼から、足りない情報は常識で補い、決められない大事な点（用途、文字を入れるか）だけを聞く。
   - サイズの目安：横長 `1536x1024`、縦長 `1024x1536`、正方形 `1024x1024`。用途の指定がなければ `config/images.json` の既定を使う。
   - 画像の中の日本語は崩れやすい。文字を入れるなら短くし、できあがりを確認する（手順4）。
3. **実行する。**
   - 生成：`python3 scripts/image.py generate -p "<指示文>" [--size ...] [--quality ...] [--out <フォルダ>] [--name <英数字の名前>]`
   - 編集：`python3 scripts/image.py edit --image <元画像> [--image <参考画像>] [--mask <マスク>] -p "<どう変えるか>" [--out ...] [--name ...]`
     - 元画像の指定がなければ、保存先の最新の画像（`ls -t <保存先>`）を候補にして、どれか確認する。
   - 保存先の指定（「〇〇フォルダに」）があれば `--out` に渡す。なければ既定（`images/output`。相対パスはプロジェクトのルートから）。
   - 送る内容だけ確かめたいときは `--dry-run`（APIを呼ばず、料金もかからない）。
4. **確認する。** 保存された画像を Read で開いて見て、依頼どおりか（特に文字、手、数、不要な要素）を一言で伝える。直すなら、変える点を絞った編集（`edit`）で1回だけ提案する。
5. **報告する。** 保存したファイルのパス、使ったモデルと主な設定、同名の `.json`（指示と設定の記録）があることを伝える。

## エラーのとき
- `モデルIDが違う可能性` と出たら、`python3 scripts/image.py models` で使えるIDを確認し、`OPENAI_IMAGE_MODEL` か `config/images.json` の `model` を直すよう案内する。モデル名は公式資料で未確認のまま設定している。
- サイズや品質が受け付けられないときは、`--size auto` や `1024x1024` で1回だけやり直す。
- 接続できないときは、ネットワークの許可設定（`api.openai.com`）を案内する。

## 依頼と実行の例
| 依頼 | 実行 |
|---|---|
| 「noteの見出し画像を作って。落ち着いた青系で、鍵とスマホ」 | `generate -p "…" --size 1536x1024 --name header` |
| 「images/output の最新の画像の背景を白にして」 | `edit --image <最新> -p "背景を白無地にして、被写体はそのまま" --name white-bg` |
| 「このロゴを透明背景のPNGにして」 | `edit --image logo.png -p "背景を透明にする" --background transparent` |
| 「3案ください」 | 枚数を伝えて確認してから `--n 3` |
| 「送る内容だけ確認したい」 | `--dry-run` |

## note記事の見出し画像
記事フォルダの `v*/titles.md` に「見出し画像の文言案」がある。使うときは、その文言を画像に入れるか（崩れやすい）、画像は絵だけにして文字はnoteのエディタで足すかを、先に決める。
AIで作った画像の扱い（表示の要否や権利）は、noteとOpenAIの最新の規約で確認してから公開する。
