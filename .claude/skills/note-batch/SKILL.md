# note記事の量産

引数：$ARGUMENTS（1つ目が本数。省略時は3本。2つ目以降はジャンルの絞り込み）

## 手順
1. `trend-researcher` を「テーマ未指定・候補を本数×2個出す」指示で起動し、`articles/_batch-<YYYYMMDD>/ideas.md` に書かせる。
   既存の `articles/*/state.json` のテーマと重複するものは除外させる。
2. 上位N本を選び、互いに読者や切り口が重なりすぎていないか確認する（重なる場合は次点と入れ替える）。
3. 1本ずつ順番に、`.claude/skills/note-article/SKILL.md` の手順をそのテーマで最後まで実行する。
   - コンテキストを節約するため、各記事の詳細はファイルに任せ、記事ごとの最終報告だけを手元に残す。
   - 1本が失敗しても止めず、次に進む。
4. 最後に一覧表で報告：テーマ／採用タイトル／価格／総合点／合格可否／要記入件数／final.md のパス。

大量に作る場合は、記事ごとに新しいセッションで動かす `scripts/batch.sh` の方がコンテキストが溢れにくい。
