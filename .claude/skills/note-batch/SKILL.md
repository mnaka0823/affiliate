# note記事の量産

引数：$ARGUMENTS（1つ目が本数。省略時は3本。`--series` があればシリーズで作る。それ以外はジャンルの絞り込み）

## 手順
1. テーマを決める。
   - `articles/_themes/` に今月作った一覧があれば、それを使ってよいかをユーザーに確認する（非対話なら使う）。
   - なければ `/note-themes` と同じ手順で、本数×2個以上のテーマ一覧を作る。
   - 既存の `articles/*/state.json` のテーマと重複するものは除く。
2. 選び方：
   - **通常**：優先度の上位N本。互いに読者や状況の分かれ方が重なりすぎていないか確認し、重なれば次点と入れ替える。
   - **`--series`**：優先度1位を起点に、「同じ読者が次に困りそうなこと」をたどってN本を選ぶ。各記事の末尾で次の記事を予告し、相互リンクする前提で作る。
3. 1本ずつ順番に、`.claude/skills/note-article/SKILL.md` の手順をそのテーマで最後まで実行する。
   シリーズの場合は、各記事の `trend-researcher` への指示に「シリーズの前後の記事のテーマ」を添える。
   - コンテキストを節約するため、各記事の詳細はファイルに任せ、記事ごとの最終報告だけを手元に残す。
   - 1本が失敗しても止めず、次に進む。
4. 最後に一覧表で報告：テーマ／採用タイトル／価格／総合点／合格可否／要記入件数／final.md のパス。シリーズならマガジン名の案と並び順も出す。

大量に作る場合は、記事ごとに新しいセッションで動かす `scripts/batch.sh` の方がコンテキストが溢れにくい。
